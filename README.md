# AI Atlas

Live Demo: https://ai-atlas-870927.onhercules.app/

AI Atlas is a premium AI learning, simulation, and career-roadmap platform designed to help beginners understand artificial intelligence in plain English and progress toward real-world AI project building.

The experience blends:
- interactive AI education
- hands-on simulations
- beginner-first explanations
- AI career guidance
- model and news tracking
- project-based learning with modern SaaS design

## Project Vision

AI Atlas helps users move from:

"I know nothing about AI" → "I understand AI" → "I can build with AI" → "I know which AI path fits me" → "I can create real AI projects"

This project is intentionally beginner-friendly while still supporting more advanced learners and developers.

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
